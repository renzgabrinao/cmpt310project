# Description

The existing Richter scale serves to report the physical strength of an earthquake, but it does not account for the socioeconomic impact and danger to human life. 

The goal of this project is to build an unsupervised clustering system (K-means) that categorizes Japan’s historical earthquake data into different risk types, which maps seismic attributes to their corresponding emergency response categories. 
This model will assist emergency response teams' decision making process by providing severity based classification given current team resources.
